# 🔐 Secure Connect

Secure Connect is a private full-stack communication and memory-sharing platform built using React, Firebase, Cloudinary, Tailwind CSS, and Framer Motion.

The platform was designed to create a secure and interactive personal space with modern real-time communication features and aesthetic UI/UX.

---

## ✨ Features

* 💬 Real-time private chat
* 🎤 Voice messages
* 📸 Image sharing
* ❤️ Message reactions
* ↩️ Reply system
* 👀 Seen status
* ⌨️ Typing indicator
* 🌄 Custom chat wallpapers
* 💌 Digital post box
* 📚 Shared memory library
* 🌙 Stargazing wishes section
* 🎵 Music sharing
* 🎬 Movie night planner
* 📝 Quote wall
* 🗺️ Memory map
* 📋 Bucket list
* 🎨 Responsive modern UI

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* Framer Motion

### Backend / Services

* Firebase Firestore
* Firebase Authentication
* Cloudinary

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Abdul-Hadee11/Secure-Connect.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file in the root directory and add:

```env
VITE_APP_PASSWORD=your_password

VITE_FIREBASE_API_KEY=your_key
VITE_FIREBASE_AUTH_DOMAIN=your_domain
VITE_FIREBASE_PROJECT_ID=your_project_id

VITE_CLOUD_NAME=your_cloudinary_name
```
